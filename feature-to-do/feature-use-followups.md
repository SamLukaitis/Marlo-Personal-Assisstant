# Feature use: follow-ups

The Portal's Feature use tab (changelog 2026-10-19) counts which of Marlowe's tools each answered
message used. Things it doesn't cover yet:

- **Joyce.** Her tools aren't counted. The same approach would work (her own tables, since Joyce
  keeps her data apart from Marlowe's) with a matching tab in the Joyce portal.
- **Things people get without asking.** Morning briefings, evening recaps, alerts and reminders
  aren't messages, so they don't appear. Whether people reply to them, tap their buttons or mute
  them would show which ones are worth keeping.
- **Trends over time.** The tab shows totals for a date range. A week-by-week view would show
  whether a feature is catching on or fading once more people have the number.
- **Repeat use.** "Used once" and "uses it every day" look the same. Counting the days each person
  used an area would separate a one-off try from a habit.
