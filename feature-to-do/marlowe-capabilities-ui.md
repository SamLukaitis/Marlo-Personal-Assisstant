# Create a UI/layout of what Marlo can do

As more tools and integrations get added (briefing preferences, Teams chat, travel/Schengen
tracking, Xero, whatever comes next), there's no single place to see everything Marlo can
currently do — it's only discoverable by asking in chat or knowing it exists. This will get harder
to navigate as the list grows. Want some kind of UI/page that lays out Marlo's capabilities
clearly, so a user (or Jake) can see the full picture at a glance instead of hunting through
conversation history.
