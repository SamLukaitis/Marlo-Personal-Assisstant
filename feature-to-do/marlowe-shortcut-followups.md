# Marlo Shortcut: later follow-ups

Ideas left out of the first version of phone actions (see `done-marlowe-shortcut.md`):

- **Android runner.** Tasker or MacroDroid can open a URL and make HTTP calls, so they could run the
  same steps from the same `/api/phone-actions` API. Today it's iPhone only.
- **User-editable rules.** Let people write their own "when X, offer Y" rules instead of relying on
  Marlo's judgement in the briefing and reminders.
- **Chrome extension.** The same idea for the desktop browser: Marlo hands over steps, the
  extension runs them after a click.
